# 大象清晰度检测

先手动将需要的照片归入野生动物，再在图库进入选择模式，选中照片，在“检测与评分”中选择“大象清晰度检测”。检测只处理本次选择，不会自动调整分类，也不改变原有总分、星级或鸟类检测结果。桌面菜单和手机操作面板均提供此入口。

检测完成后可查看本次照片，并按大象头眼清晰度排序。详情页独立显示大象检测结果，可以选择每头大象查看原图局部：紫色圆表示实际测量的眼周，蓝色圆表示实际测量的头部。结果存于照片库；关闭进度窗口后，可从“后台任务”查看进度或停止，也可重新打开检测窗口。停止后保留已完成结果，再选同批照片运行时跳过仍然有效的结果。

## 评分依据

- 目标检测及象体分割使用与鸟类共用的多类别模型，但只提取大象类别。
- 头眼定位使用 RTMPose（实时姿态估计模型）的 AP-10K（野外动物姿态数据集）版本。眼睛与颈部位置定义头部尺度，不用象鼻尖估算头部大小。
- 在原图和水平镜像中分别定位，再使用较近的原图上下文复核可见眼睛。没有确认的另一只眼候选保留在诊断证据中，不凭候选置信度评分。
- 只在原图象体内部的眼周和头部测量边缘过渡宽度，排除分割轮廓和背景。眼周测量半径为眼颈距离的 0.12 倍，头部半径为 0.65 倍；不放大小目标获取虚假的细节。
- 每个已核验眼周和头部测量中的最低值决定该大象的 0–10 分。身体纹理、另一部位或背景清楚不能补偿已测得的眼周模糊。多头大象取有效参考分最高者作为照片的大象参考分。
- 大象身体触及画面边界不直接否定头眼；实际测量区域必须有足够原图覆盖和有效内部细节。无法可靠定位或测量时不评分，显示“待复核”。

这是实验性参考分，尚未用独立人工标注的大象照片进行校准。内部的保守区间为不高于 3 分、至少 7.5 分及中间待复核区间；界面以参考分和可检查的测量区域为主，不应将区间理解为已验证的摄影合格线。模型响应值仅用于定位检查，不是眼睛可见性的校准概率，更不是清晰度分数。

## 模型与结果保存

首次使用下载所需模型，照片在本机处理。共用的目标模型保存在 `pretrained_models/birds/`；大象关键点模型单独保存在 `pretrained_models/elephants/rtmpose-m-ap10k.onnx`，下载内容通过固定摘要核对。已有共用权重无需重新下载。

大象结果单独使用 `photos.elephant_*` 字段和 `elephant_detection_jobs` 表；数据库初始化会自动补齐。有效结果缓存同时核对原图文件大小、修改时间、检测规则、分块模式和最小面积门槛。原图变化或规则过期后，详情和局部预览会提示重新检测。调整面积门槛会重新检测；默认门槛为定位框占照片面积至少 1%。

后台任务与扫描、重算、鸟类检测共用照片库互斥锁。任务查询、停止、本次照片范围和预览沿用现有用户权限隔离。
